Problema

La información juvenil útil está dispersa en múltiples canales, lo que dificulta encontrar oportunidades de empleo, formación, vivienda, ocio o recursos cercanas.

Dispersión

Los jóvenes consultan portales, redes, tablones y grupos sin un punto central.

Filtro territorial

Resulta complicado localizar contenido relevante por provincia o comunidad.

Participación

Faltan canales sencillos para proponer ideas, sugerencias y consultar actividades locales.

Solución

CityPAJ centraliza la información juvenil en una aplicación web con filtros por territorio, categoría y tipo de contenido, además de espacios de participación y moderación.

Anuncios

Publicación y consulta de ofertas de empleo, formación, vivienda, ocio y servicios.

Filtros territoriales

Selección por comunidad autónoma y provincia para mostrar contenido relevante.

Comunidad

Espacio de publicaciones locales y comentarios por provincia.

Sugerencias

Buzón para enviar mejoras o nuevas ideas a la plataforma.

Propuestas

Consulta y apoyo a propuestas ciudadanas juveniles.

Cultura y eventos

Actividades, convocatorias y recursos culturales organizados.

Moderación

Revisión de anuncios y reportes antes de su publicación o tras denuncias.

Administración

Gestión de usuarios, contenidos y paneles de control.

Arquitectura técnica

Frontend, backend y base de datos separados. El frontend nunca accede directamente a MySQL; la comunicación fluye siempre a través de la API REST.

Datos ficticios

Usuarios, anuncios, recursos, eventos y propuestas de prueba generados para la evaluación académica.

Conexión segura

El navegador nunca contiene credenciales de MySQL. El backend centraliza el acceso y la autenticación.

Health check

El endpoint /health confirma la conexión a la base de datos. /api/demo/status devuelve métricas básicas.

Modelo social

CityPAJ se concibe como un proyecto de finalidad social y sin ánimo de lucro. No incorpora pasarela de pago ni gestiona transacciones económicas.

Sin ánimo de lucro

El objetivo es facilitar el acceso a la información y la participación juvenil, no generar ventas.

Sin pagos

No se tratan datos bancarios ni se integra TPV, reduciendo riesgos legales y técnicos.

Sostenibilidad

El mantenimiento futuro puede apoyarse en entidades públicas, educativas o juveniles.

Instalación local

Requisitos: Docker Desktop. No es necesario instalar Node.js ni MySQL manualmente.

git clone https://github.com/carmendmv/citypaj.git cd citypaj docker compose up --build

Una vez levantado: http://localhost:3001 y backend http://localhost:3002/health.
